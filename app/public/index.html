Deploy a Bot

Upload a ZIP of your Node.js bot. It must include a package.json with a "main" or "start" script, or an index.js file.

Deploy from GitHub

Connect your GitHub account, then choose a repository to deploy.

GitHub sign-in is not set up on this server yet. The panel owner needs to add the GitHub settings first.
Signed in as—

Deploy from a Git address

Paste a GitHub repo address. Public repos need nothing else. For a private repo, add a username and access token.

Use "npm start" or "node yourfile.js". Other shell commands are not allowed. The token is used once to download the code and is not saved.

Upload a ZIP

Or upload your bot as a ZIP file.

Bots run with no access to the panel's files or secrets, and are stopped if they use more than 192 MB of memory. Keep secrets such as bot tokens in the Settings for your bot after uploading, not inside the ZIP.
